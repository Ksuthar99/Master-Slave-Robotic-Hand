Master-Slave Robotic Hand 🤖

This is my beginner robotics project using ESP32, potentiometers, and servo motors.

Components
ESP32
5 Potentiometers
5 Servo Motors
Wokwi Simulator
How It Works

Each potentiometer controls one servo motor, simulating the movement of a robotic finger.

Status

✅ Working simulation in Wokwi.

🔜 Physical robotic hand is the next step.

Technologies

Arduino C++ | ESP32 | Wokwi
